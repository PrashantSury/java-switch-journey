| 2 Nov | Day 04 Part B2 (Spring, late push `0600df2`) | Added `@ExceptionHandler(Exception.class)` that answers every unhandled exception with a **500**, `detail` "Required json body is bad or empty." and `errorCode` `BAD_JSON_OR_EMPTY_JSON`, with no log line. Probed on the pushed code: `POST` with `text/plain` (should be 415), `PATCH /api/students` (405) and `GET /api/students/abc` (400) all became 500, because `ExceptionHandlerExceptionResolver` runs before `DefaultHandlerExceptionResolver`. This is the gotcha in section 5 and interview question 6 of the B2 spec. Lesson: a catch-all must not swallow exceptions that already carry their own status, and the full cause goes to the log at `error`, a fixed generic text goes to the client. | 5 Nov | 9 Nov |
| 16 Nov | labs Chapter 2 Task 4 (premature mapping in `8f48e9b`) | Wrote `@GetMapping("/accounts/above?balance=N")`, copying the client URL from the task comment into the annotation. A path pattern matches only the path; the query string is bound separately by `@RequestParam`, and inside a pattern `?` is a one-character wildcard, so the mapping never matches `/accounts/above?balance=10000` (task4a-d 404). Correct: `@GetMapping("/accounts/above")` + `@RequestParam int balance` (missing or non-numeric → 400 from Spring). Lesson: before writing a mapping, say "the path is ___, the params are ___". Pack: [day25.md evening](../tasks/day25.md#-weak-topic-pack-1-requestparam-vs-the-path-pattern-main-pack). | 19 Nov | 23 Nov |
| 16 Nov | Maven scopes follow-up MCQ (chat, ~9:05 PM IST) | Recalled the scopes grid 10/10, but for a WAR deployed to an external Tomcat with the servlet API left at `compile`, picked C instead of B. `compile` packs `servlet-api` into `WEB-INF/lib`, so the app ships its own copy next to Tomcat's and the two copies can clash at class loading. The servlet API belongs at `provided`: on the compile and test classpaths, not packaged, because the container supplies it. Lesson: for each dependency ask "who supplies this jar at runtime, my package or the server?" | 19 Nov | 23 Nov |
